# 二、生成模型的基本概念

生成模型（Generative Model）的目标是：

[
学习数据分布; p(x)
]

即通过模型学习真实数据的概率分布，使模型能够：

- 生成新的样本
- 模拟真实数据结构

生成模型常见任务包括：

- 图像生成
- 文本生成
- 视频生成
- 语音生成

典型应用：

- 文生图
- 文生视频
- 数据增强
- 内容创作

当前主流生成模型技术路线包括：

| 类别           | 代表模型    |
| -------------- | ----------- |
| 自编码生成模型 | VAE         |
| 对抗生成模型   | GAN         |
| 扩散生成模型   | Diffusion   |
| 自回归生成模型 | Transformer |

# 三、潜变量（Latent Variable）的概念

生成模型通常假设：

真实数据由 **不可观测的潜在变量** 生成。

形式化表示：

[
z \rightarrow x
]

其中：

- (z)：潜变量（latent variable）
- (x)：观测数据

直观理解：

latent 表示 **数据的压缩表示或隐藏因素**。

例如在图像中：

latent 可能编码：

- 物体形状
- 颜色
- 结构
- 语义信息

------

# 四、先验分布与后验分布

在潜变量模型中存在两个重要概率分布：

### 1 先验分布（Prior）

先验表示在观测数据之前，对潜变量的假设。

通常设为：

[
p(z)=N(0,1)
]

即标准正态分布。

作用：

- 约束 latent 空间结构
- 保证 latent 空间连续可采样

------

### 2 后验分布（Posterior）

后验表示：

在观测到数据 (x) 之后，潜变量的真实分布。

形式：

[
p(z|x)
]

但由于计算困难，VAE使用近似后验：

[
q(z|x)
]

由 encoder 网络进行估计。

------

# 五、VAE模型结构

**Variational Autoencoder** 是一种典型的 **潜变量生成模型**。

模型结构包括两个部分：

### 1 Encoder

作用：

将图像映射到潜变量分布。

[
x \rightarrow q(z|x)
]

输出：

- latent 均值 μ
- latent 方差 σ

------

### 2 Decoder

作用：

根据 latent 生成图像。

[
z \rightarrow x'
]

decoder 学习条件分布：

[
p(x|z)
]

------

# 六、VAE训练目标

VAE训练优化 **ELBO（Evidence Lower Bound）**：

目标函数包含两部分：

### 1 重建损失（Reconstruction Loss）

[
E_{q(z|x)}[\log p(x|z)]
]

作用：

保证 decoder 能够从 latent 恢复原图。

------

### 2 KL散度（KL Divergence）

[
KL(q(z|x)||p(z))
]

作用：

约束 latent 分布接近先验：

[
p(z)=N(0,1)
]

这样 latent 空间具有连续结构。

------

# 七、VAE生成图像机制

VAE生成图像的过程：

1. 从先验分布采样 latent

[
z \sim N(0,1)
]

1. 输入 decoder

[
x = decoder(z)
]

1. 生成新图像

因此：

生成的随机性来自 **latent采样**，而不是 decoder 本身。

decoder 本质是：

[
x=f_\theta(z)
]

即一个确定性的神经网络映射。

------

# 八、Latent Space 的意义

VAE学习到一个 **连续的潜在空间**。

在 latent 空间中：

相近的向量对应相似图像。

例如：

```
z1 → 猫
z2 → 狗
```

中间点：

```
0.5z1 + 0.5z2 → 猫狗混合
```

这种性质称为：

**latent interpolation**

说明 latent 空间具有语义结构。

------

# 九、VAE生成图像质量问题

VAE生成图像通常存在：

- 模糊
- 细节缺失

原因：

VAE优化的是 **最大似然估计**：

[
\log p(x)
]

在存在多个可能图像时，模型可能生成平均结果。

因此生成图像不够锐利。

------

# 十、VAE在现代生成模型中的作用

尽管VAE生成能力有限，但在现代生成模型中仍然非常重要。

例如在 **Stable Diffusion** 中：

VAE用于：

```
pixel space ↔ latent space
```

完整生成流程：

```
image
 ↓
VAE encoder
 ↓
latent
 ↓
diffusion model
 ↓
latent
 ↓
VAE decoder
 ↓
image
```

这样可以：

- 大幅降低计算量
- 提高生成效率

# 一、先理解：什么是生成模型

生成模型本质是学习 **数据分布**

[
p(x)
]

或者条件分布

[
p(x|c)
]

目标是：

- **生成新的样本**
- **补全缺失信息**
- **建模世界状态**

例如：

| 模型             | 生成内容    |
| ---------------- | ----------- |
| LLM              | 文本        |
| Stable Diffusion | 图像        |
| VAE              | 图像/潜变量 |
| World Model      | 未来状态    |

[

**VAE**

[

- VAE

- 对抗训练

# 一、概率建模基础（生成模型的数学核心）

生成模型本质是 **学习数据分布**。

目标：

[
p(x)
]

或者

[
p(x|c)
]

例如：

- 生成图像
- 生成文本
- 生成视频

这里需要理解几个关键概念：

### 1 最大似然估计（MLE）

核心思想：

[
\theta^*=\arg\max_\theta \sum \log p_\theta(x)
]

这是几乎所有生成模型训练目标。

------

### 2 KL散度

[
KL(q(x)||p(x))
]

衡量两个分布差异。

在 **Variational Autoencoder** 中非常重要。

------

### 3 ELBO

VAE 的训练目标：

[
\log p(x) \ge ELBO
]

ELBO：

[
\mathbb{E}[\log p(x|z)]-KL(q(z|x)||p(z))
]

理解：

- latent variable
- variational inference

------

# 二、自编码生成模型（理解 latent space）

生成模型第一条重要路线：

**AutoEncoder**

结构：

```
x → encoder → z → decoder → x'
```

目标：

压缩 + 重建。

------

### 1 AutoEncoder

学习：

- representation
- reconstruction

但缺点：

不能真正生成。

------

### 2 Variational AutoEncoder

代表模型：

Variational Autoencoder

关键思想：

latent space 变成概率分布：

[
z \sim N(\mu,\sigma)
]

重要技术：

**reparameterization trick**

[
z=\mu+\sigma\epsilon
]

理解后你就会知道：

为什么 diffusion 可以在 latent space 生成。

------

### 3 VQ-VAE

代表：

VQ-VAE

创新：

连续 latent → **离散 token**

意义：

这是 **视觉 token 化** 的重要一步。

后来很多模型用：

- image token
- video token

# 第一阶段：生成模型基础（理解 latent）

------

## 1 VAE（2013）

Variational Autoencoder

论文：

**Auto-Encoding Variational Bayes**

核心思想：

把 AutoEncoder 变成 **概率生成模型**。

模型结构：

```
x → encoder → z ~ N(μ,σ)
           ↓
       decoder
           ↓
           x'
```

核心公式：

- ELBO
- KL散度

你要理解：

- latent space
- variational inference
- reparameterization trick

意义：

第一次提出 **可学习的 latent distribution**。

------

## 2 VQ-VAE（2017）

VQ-VAE

论文：

**Neural Discrete Representation Learning**

核心创新：

latent 不再是连续变量，而是 **离散 token**。

```
encoder → codebook → decoder
```

意义：

视觉数据可以像文本一样 **token 化**。

后续很多模型使用：

- image token
- video token

# 2026年现在用的图像生成视频生成模型不是sora什么的吗？它用到了什么技术了？是以上提到的吗

是的，**2026 年最先进的视频生成模型**（比如 **Sora**）确实已经远远超过了早期的 **Stable Diffusion** 那一代模型。但**核心技术其实还是从你刚刚学的这些生成模型演化出来的**，只是做了几次非常关键的升级。

我给你拆开讲：**Sora / 现代视频生成模型到底用了哪些技术**。

------

# 一、现代视频生成模型的核心技术框架

像 **Sora** 这种模型，大致结构可以理解为：

```
文本 prompt
     ↓
text encoder (LLM / CLIP)
     ↓
video diffusion transformer
     ↓
latent video
     ↓
video decoder
```

核心其实就是三部分：

1️⃣ **扩散模型（Diffusion）**
2️⃣ **Transformer**
3️⃣ **Latent 表示**

所以你之前看到的这些技术：

- **Denoising Diffusion Probabilistic Model**
- **Latent Diffusion Model**
- **Vision Transformer**

其实全部都在里面。

只是规模和结构升级了。

------

# 二、Sora的最大技术变化

早期图像生成模型（如 Stable Diffusion）：

```
UNet + diffusion
```

而 **Sora 的关键升级是：**

### Diffusion + Transformer

也就是：

**Diffusion Transformer**

很多论文叫：

**DiT（Diffusion Transformer）**

代表模型：

- DiT

结构变成：

```
latent patches
      ↓
transformer
      ↓
predict noise
```

这和你学的 **ViT** 其实非常像。

------

# 三、Sora的第二个核心技术：视频 token

视频其实是：

```
height × width × time
```

如果直接扩散：

计算量爆炸。

所以必须先压缩。

这一步通常用：

- **VAE**
- **VQ-VAE**

比如：

VQ-VAE

作用：

```
video
 ↓
latent video tokens
```

Sora其实是在 **latent video space** 里做 diffusion。

------

# 四、视频生成最难的问题：时间一致性

图像生成很简单：

生成一张图。

但视频需要：

```
frame1 → frame2 → frame3
```

要保证：

- 物体不消失
- 人物不变形
- 动作连续

所以视频模型必须学习：

```
spatial + temporal attention
```

Transformer就很适合做这个。

# 一、问题背景：为什么需要 VAE

在生成模型中，我们希望学习真实数据分布：

[
p_\theta(x)
]

其中

- (x)：观测数据（例如图像）
- (\theta)：模型参数

目标是让模型能够从该分布中 **生成新的样本**。

------

## 1. 引入隐变量模型

很多复杂数据难以直接建模，因此引入 **隐变量 (z)**：

[
p_\theta(x)=\int p_\theta(x|z)p(z)dz
]

含义：

- (z) 表示数据的 **潜在表示（latent variable）**
- (p(z)) 是先验分布（通常设为标准正态）

生成过程：

1. 从先验分布采样
   [
   z \sim p(z)
   ]
2. 再生成数据

[
x \sim p_\theta(x|z)
]

这就是 **生成模型的概率结构**。

------

# 二、最大似然训练的困难

训练目标通常是 **最大化似然**：

[
\max_\theta \log p_\theta(x)
]

但由于：

[
p_\theta(x)=\int p_\theta(x|z)p(z)dz
]

这个积分通常 **不可计算**。

原因：

- (z) 的维度很高
- 积分无法解析求解

因此需要 **近似推断（variational inference）**。

------

# 三、变分推断思想

引入一个 **近似后验分布**：

[
q_\phi(z|x)
]

其中：

- (q_\phi(z|x)) 由神经网络建模
- (\phi) 是参数

目标：

[
q_\phi(z|x) \approx p_\theta(z|x)
]

也就是：

用 **encoder** 近似真实后验。

------

# 四、KL散度

文章中强调了 **KL divergence**。

KL散度定义：

[
KL(q||p)=\sum q(x)\log \frac{q(x)}{p(x)}
]

性质：

[
KL(q||p) \ge 0
]

当且仅当

[
q=p
]

时取0。

KL散度衡量：

**两个概率分布之间的差异**。 ([CSDN博客](https://blog.csdn.net/heyyyyyyyi/article/details/144183958?utm_source=chatgpt.com))

------

# 五、ELBO推导（核心）

对数据对数似然：

[
\log p_\theta(x)
]

进行变分分解：

[
\log p_\theta(x)
= ELBO + KL(q_\phi(z|x)||p_\theta(z|x))
]

由于：

[
KL \ge 0
]

因此得到：

[
ELBO \le \log p_\theta(x)
]

ELBO（Evidence Lower Bound）：

## [ ELBO = E_{q_\phi(z|x)}[\log p_\theta(x|z)]

KL(q_\phi(z|x)||p(z))
]

这就是 **VAE训练目标**。

------

# 六、ELBO的两个部分

## 1 Reconstruction term

[
E_{q_\phi(z|x)}[\log p_\theta(x|z)]
]

含义：

- 用 latent variable (z) 重建数据 (x)

对应：

**decoder**

目标：

重建误差最小。

------

## 2 Regularization term

[
KL(q_\phi(z|x)||p(z))
]

作用：

让 latent distribution 接近先验：

[
p(z)=N(0,1)
]

意义：

- 让 latent space 结构化
- 可以随机采样生成数据

------

# 七、VAE网络结构

VAE由两部分组成：

### 1 Encoder

[
x \rightarrow (\mu,\sigma)
]

输出：

[
q_\phi(z|x)=N(\mu,\sigma^2)
]

------

### 2 Sampling

从分布采样：

[
z \sim N(\mu,\sigma^2)
]

------

### 3 Decoder

[
z \rightarrow x'
]

生成重建样本。

------

# 八、重参数化技巧（Reparameterization Trick）

直接采样 (z) 无法反向传播。

VAE使用：

[
z=\mu+\sigma\epsilon
]

其中：

[
\epsilon \sim N(0,1)
]

这样：

- (\mu,\sigma) 可导
- 可以用 **backpropagation**

------

# 九、VAE整体训练目标

最终损失函数：

[

- E_{q(z|x)}[\log p(x|z)]

- 

KL(q(z|x)||p(z))
]

解释：

第一项：

- reconstruction loss

第二项：

- distribution regularization

# 先验，后验是什么意思

“**先验（prior）**”和“**后验（posterior）**”是 **Bayesian statistics** 里的两个核心概念，也是理解 **Variational Autoencoder** 等生成模型必须掌握的基础。

我会按 **直觉 → 数学定义 → 在 VAE 中的含义** 来解释。

------

# 一、直觉理解

简单说：

- **先验（prior）**：在看到数据之前，对某个变量的假设
- **后验（posterior）**：看到数据之后，对这个变量更新后的认识

可以理解为：

```text
先验 = 事先的猜测
后验 = 看完证据后的判断
```

------

# 二、一个直观例子

假设你要判断一个袋子里红球的比例。

### 1 先验

在没看到任何球之前，你可能认为：

```text
红球概率 ≈ 0.5
```

这就是：

[
p(\theta)
]

这里：

- (\theta)：红球比例
- (p(\theta))：先验分布

------

### 2 观察数据

假设你抽了 10 个球：

```text
9 个红球
1 个蓝球
```

------

### 3 更新信念

根据数据，你会觉得：

```text
红球比例可能更高
```

得到新的分布：

[
p(\theta|x)
]

这就是 **后验分布**。

------

# 三、数学表达（贝叶斯公式）

先验和后验通过 **贝叶斯公式**联系：

p(\theta|x)=\frac{p(x|\theta)p(\theta)}{p(x)}

含义：

- (p(\theta))：先验
- (p(x|\theta))：似然（数据出现的概率）
- (p(\theta|x))：后验
- (p(x))：归一化常数

一句话理解：

```text
后验 = 先验 × 数据信息
```

------

# 四、在 VAE 中的含义

在 **Variational Autoencoder** 中：

我们有一个 latent 变量 (z)。

------

## 1 先验

VAE假设：

[
p(z)=N(0,1)
]

意思是：

```text
latent空间大致服从标准正态分布
```

这是一个 **人为设定的假设**。

------

## 2 后验

当看到图像 (x) 时：

我们希望知道：

```text
这张图像对应哪个latent？
```

真实后验是：

[
p(z|x)
]

但它通常 **很难计算**。

------

## 3 近似后验

VAE用一个神经网络来近似：

[
q_\phi(z|x)
]

这个网络就是：

```text
encoder
```

它输出：

```text
μ(x), σ(x)
```

表示：

```text
z ~ N(μ, σ)
```

------

# 五、为什么要让后验接近先验

VAE训练时有一个 KL loss：

[
KL(q(z|x)||p(z))
]

作用是：

```text
让后验分布接近先验分布
```

这样做的好处是：

- latent space 连续
- 可以随机采样生成数据

------

# 六、直观总结

在 VAE 中：

| 概念          | 含义                   |
| ------------- | ---------------------- |
| 先验 (p(z))   | 我们假设 latent 的分布 |
| 后验 (p(z     | x))                    |
| 近似后验 (q(z | x))                    |

流程：

```text
先验 p(z)
     ↓
生成图像
     ↓
观察图像 x
     ↓
推断 latent
     ↓
后验 p(z|x)
```

------

# 七、用一句最简单的话总结

**先验（prior）**

> 在看到数据之前的概率分布。

**后验（posterior）**

> 在看到数据之后更新得到的概率分布。

------

如果你继续学生成模型，下一个经常让人困惑的问题其实是：

**为什么 VAE 的目标函数里会出现 KL 散度？**

这个问题其实是理解 **ELBO 和变分推断** 的关键，也是很多生成模型课程最容易讲不清的地方。

# vae是输出和原图相似的东西对吗

是的，但需要 **更精确地理解**。
**Variational Autoencoder（VAE）在训练时确实会输出与原图相似的图像**，但这只是训练目标的一部分，它的核心目的是 **学习数据的潜在分布（latent distribution）**。

我从 **训练过程 → 为什么相似 → 为什么又不完全一样 → 和普通AutoEncoder的区别** 讲清楚。

------

# 一、VAE训练时确实会输出“和原图相似”的图像

训练时流程是：

```
image x
   ↓
encoder
   ↓
latent z
   ↓
decoder
   ↓
reconstructed image x'
```

目标是：

[
x' \approx x
]

也就是说：

> decoder 生成的图像 **尽量接近输入图像**。

因此你看到的输出通常是：

- 同一只猫
- 同一个数字
- 同一张脸

但会有一些 **模糊或细节差异**。

------

# 二、为什么VAE要做“重建”

训练目标的一部分是 **重建误差（reconstruction loss）**：

[
\mathbb{E}_{q(z|x)}[\log p(x|z)]
]

直观意义：

```
encoder 把图像压缩成 latent
decoder 必须从 latent 恢复图像
```

如果恢复不好：

说明 latent 没学到有效信息。

------

# 三、但VAE不会完全复制原图

和普通 AutoEncoder 不同，VAE 在训练时有一个额外约束：

让 latent 分布接近一个先验分布。

通常是：

[
p(z)=N(0,1)
]

这个约束通过 **KL loss** 实现：

[
KL(q(z|x) || p(z))
]

作用：

```
限制 latent 的分布形状
```

结果就是：

- latent 不会精确编码每个像素
- 会丢掉一些细节

所以 VAE 重建图像通常：

```
结构正确
细节模糊
```

------

# 四、为什么VAE生成的图像经常模糊

因为 VAE 优化的是 **最大似然**：

[
\log p(x)
]

这会导致一种现象：

如果有多个可能的图像，模型会生成 **平均结果**。

例如：

```
真实数据：
猫A
猫B
```

模型可能生成：

```
猫A和猫B之间的平均猫
```

所以看起来会 **有点模糊**。

这也是为什么后来很多模型用：

- Generative Adversarial Network
- Stable Diffusion

来生成更清晰图像。

------

# 五、VAE和普通AutoEncoder的区别

普通 AutoEncoder：

```
image → encoder → latent → decoder → image
```

目标：

```
尽可能完全重建
```

latent：

```
没有分布限制
```

------

VAE：

```
image → encoder → latent distribution → sample z → decoder → image
```

latent：

```
必须接近 N(0,1)
```

所以：

| 模型        | 目标         |
| ----------- | ------------ |
| AutoEncoder | 压缩 + 重建  |
| VAE         | 学习数据分布 |

------

# 六、训练阶段 vs 生成阶段

很多人第一次学 VAE 会混淆这两件事。

### 训练阶段

输入：

```
原始图像
```

输出：

```
相似图像
```

------

### 生成阶段

输入：

```
随机 z
```

流程：

```
z → decoder → image
```

输出：

```
新的图像
```

------

# 七、总结一句话

VAE在训练时：

> **输入一张图像 → 输出一张结构相似的重建图像。**

但它真正学到的是：

> **一个可以生成图像的 latent 空间。**

------

如果你继续深入生成模型，下一步会出现一个 **非常关键的概念**：

**latent diffusion**

例如在 **Stable Diffusion** 里：

```
image → VAE → latent → diffusion → latent → VAE → image
```

很多人第一次看到会有一个疑问：

**为什么扩散模型不直接生成像素，而是生成 latent？**

这个问题其实是 **现代生成模型设计的关键点之一**。

# 一个可以生成图像的 latent 空间，它是每次decoder都随机拼凑一个图像吗？

不是“随机拼凑”。更准确地说：

> **decoder 是一个确定性的函数，它把一个 latent 向量 (z) 映射成一张图像。**

随机性来自 **latent 的采样**，而不是 decoder 在拼图。

我们一步一步把机制讲清楚。

------

# 一、VAE生成图像的真实过程

在 **Variational Autoencoder** 中，生成流程是：

### 1 先随机采样 latent

[
z \sim N(0,1)
]

也就是从一个高维高斯分布中随机取一个向量。

例如：

```text
z = [0.3, -1.2, 0.7, ...]
```

------

### 2 decoder生成图像

然后输入 decoder：

```text
z
↓
decoder(z)
↓
image
```

decoder 是一个神经网络，本质是：

[
x = f_\theta(z)
]

也就是说：

> **每一个 z 都会被映射成一张图像。**

------

# 二、为什么看起来像“随机生成”

因为每次采样的 **z 不同**：

```text
z1 → decoder → image1
z2 → decoder → image2
z3 → decoder → image3
```

所以看起来像随机生成图像。

但实际上：

- decoder 是 **固定函数**
- 随机的是 **z**

------

# 三、latent空间其实是“图像空间的坐标系”

你可以把 latent space 想成一个 **高维坐标系**：

```text
latent space

z1 ---- z2 ---- z3
 |       |       |
猫1     猫2     猫3
```

不同位置的 latent：

对应不同图像。

所以 decoder 做的事情是：

```text
latent坐标 → 图像
```

而不是拼凑。

------

# 四、为什么 decoder 能生成合理图像

因为在训练时 decoder 学到了：

[
p(x|z)
]

也就是：

> 给定 latent (z)，什么样的图像是合理的。

训练流程：

```text
image
 ↓
encoder
 ↓
latent
 ↓
decoder
 ↓
reconstruction
```

模型逐渐学会：

```text
某些 latent → 猫
某些 latent → 狗
某些 latent → 车
```

------

# 五、为什么可以生成“新图像”

因为 latent 空间是 **连续的**。

例如：

```text
z1 → 猫
z2 → 狗
```

中间：

```text
0.5z1 + 0.5z2 → 猫狗混合
```

这种性质叫：

**latent interpolation**

------

# 六、为什么VAE生成图像经常模糊

因为 decoder 不是在拼图，而是在 **生成概率分布的平均值**。

当多个图像都可能对应某个 latent 时：

模型可能生成：

```text
平均图像
```

这就是模糊的原因。

------

# 七、和现代生成模型的关系

在 **Stable Diffusion** 中：

流程其实是：

```text
随机latent
↓
diffusion生成latent
↓
VAE decoder
↓
图像
```

也就是说：

- diffusion 负责生成 **latent**
- VAE decoder 负责把 latent **变成像素图像**

------

# 八、一句话总结

VAE不是随机拼图，而是：

```text
随机latent → 神经网络函数 → 图像
```

decoder 就像一个 **“latent → 图像”的生成器函数**。

------

如果你继续深入生成模型，其实马上会遇到一个 **非常关键的问题**：

> **latent 空间为什么要强制接近正态分布 (N(0,1))？**

这个问题是理解 **VAE 为什么需要 KL loss** 的核心，也是很多人学 VAE 时真正的难点。

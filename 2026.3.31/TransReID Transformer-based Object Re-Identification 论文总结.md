# TransReID: Transformer-based Object Re-Identification 论文总结

本文由阿里达摩院研究团队提出，首次将纯Transformer架构应用于目标重识别（ReID）任务，提出TransReID框架，有效解决传统CNN方法在ReID任务中的局限性，在多个数据集上实现性能突破，入选ICCV 2021，为ReID领域提供了全新的研究思路与强基线模型。

# 一、研究背景与动机

## 1. ReID任务本质

目标：在跨摄像头、非重叠视场的场景中，精准匹配同一目标（涵盖行人和车辆），是计算机视觉领域中具有重要实用价值的任务，广泛应用于智慧交通、智能城市等场景。

核心挑战：

- **跨视角差异（view / camera bias）**：不同摄像头的角度、光照、成像参数不同，导致同一目标外观存在显著差异，是ReID任务的核心难点之一；
- **遮挡（occlusion）**：目标可能被行人、障碍物等遮挡，导致关键特征缺失，影响匹配精度；
- **细粒度区分（fine-grained）**：不同目标可能具有相似的外观（如相似衣着、车型），需捕捉细微特征差异才能实现精准匹配。

## 2. CNN方法的局限

传统ReID方法主要依赖CNN架构，但受限于自身结构，存在明显不足：

- 局部感受野特性，导致模型难以建模目标的全局上下文关系；
- pooling和stride等下采样操作会造成目标细节信息丢失，不利于细粒度特征提取；
- 难以灵活融合非视觉信息（如camera ID、视角信息），而这些信息对缓解跨摄像头偏差至关重要。

👉 本质问题：**ReID任务需要“全局特征+细粒度特征+上下文信息”的联合建模，而CNN天然偏局部建模，无法很好满足这一需求**。

## 3. Transformer的机会

Transformer（尤其Vision Transformer，ViT）的结构特性，恰好弥补了CNN在ReID任务中的不足，为其提供了新的解决思路：

- 全局自注意力机制（global context），可高效建模目标的全局上下文关系，捕捉长距离依赖；
- patch-level建模方式，将图像分割为多个patch进行处理，天然适合ReID任务的细粒度特征提取与全局匹配需求；
- 灵活的embedding融合能力，可轻松融入非视觉信息，解决跨摄像头偏差问题。

👉 作者提出关键研究问题： > 能否用“纯Transformer”替代CNN作为backbone，实现更优的ReID性能？

# 二、核心贡献（3点核心创新）

## 1️⃣ 首个纯Transformer ReID框架

- 提出名为 **TransReID** 的全新框架，是ReID领域首个不依赖CNN backbone、完全基于Transformer构建的模型；
- 以Vision Transformer（ViT）为基础，构建了强基线模型 **ViT-BoT**，为后续纯Transformer ReID研究提供了基准；
- 打破了ReID领域对CNN的依赖，证明了纯Transformer架构在ReID任务中的可行性与优越性，在6个数据集上均超越当时的SOTA CNN方法。

👉 核心突破：完全脱离CNN backbone，仅依靠Transformer实现ReID任务的精准匹配。

## 2️⃣ Side Information Embedding（SIE，侧信息嵌入）

👉 核心目标：建模ReID任务中的**非视觉信息**，缓解跨摄像头、跨视角带来的特征偏差。

### 核心思想

将camera ID、viewpoint（视角）等非视觉辅助信息，编码为可学习的embedding，与图像的patch embedding、位置embedding进行融合，具体公式如下：

$$z = x_{patch} + e_{pos} + e_{camera}$$

其中，$$e_{camera}$$ 可扩展为包含视角等信息的综合侧信息嵌入，最终构成模型输入的一部分，与可学习的位置嵌入类似，实现多模态信息的统一建模。

### 核心作用

- 有效减少跨摄像头偏差，降低不同摄像头成像差异对特征匹配的影响；
- 将视觉信息与非视觉信息统一到同一特征空间，实现多来源信息的联合建模，提升模型泛化能力。

👉 本质：**把跨摄像头、跨视角带来的domain bias（领域偏差）显式建模到特征空间中**，从根源上缓解偏差对匹配精度的影响，相较于CNN方法中复杂的定制化偏差抑制设计，更具通用性。

## 3️⃣ Jigsaw Patch Module（JPM，拼图补丁模块）

👉 核心目标：增强模型的局部特征鲁棒性，弥补纯Transformer在局部建模上的天然不足。

### 核心做法

- 对图像分割后的patch进行随机打乱（shuffle）和移位（shift）操作；
- 将打乱后的patch重新分组，形成新的patch组合；
- 将重新组合的patch输入Transformer进行学习，强制模型捕捉patch之间的关联关系而非固定位置信息。

### 两个关键作用

1. 强制模型学习 **位置不变特征**，降低目标姿态变化、位置偏移对特征提取的影响；
2. 每个重组后的patch组包含更大范围的图像信息，形成“伪全局”特征，兼顾局部细节与全局关联，提升模型对遮挡场景的适应能力。

👉 本质：**数据增强与结构正则化的结合**，通过破坏patch的原始空间结构，迫使模型学习更具判别力的鲁棒特征，而非依赖固定的空间位置信息，进一步提升细粒度匹配能力。

# 三、模型结构

TransReID整体采用 **双分支结构**，兼顾全局特征与局部特征的提取与融合，具体流程如下：

```plain
                输入图像
                    ↓
             Patch Embedding（补丁嵌入）
                    ↓
             Transformer Encoder（编码）
                 /      \
                /        \
      Global Branch   Jigsaw Branch
         (CLS token)   (JPM + 局部特征)
                \        /
                 \      /
                Feature Fusion（特征融合）
                    ↓
                  Loss（损失计算）
```

## 1. 输入表示（基于ViT）

首先将输入图像（维度为$$x \in \mathbb{R}^{H \times W \times 3}$$）分割为N个互不重叠的patch，得到patch序列 $${x_1, x_2, ..., x_N}$$；

随后将每个patch映射为固定维度的token，同时加入CLS token（用于全局特征提取）、位置embedding（$$E_{pos}$$）和SIE嵌入（$$E_{SIE}$$），最终形成模型的初始输入token序列：

$$z_0 = [x_{cls}; x_1; ...; x_N] + E_{pos} + E_{SIE}$$

## 2. Transformer编码

采用标准的多层Transformer Encoder结构，每一层包含多头自注意力（MSA）和多层感知机（MLP）两个子模块，同时引入层归一化（LN）和残差连接，确保模型稳定训练，具体公式如下：

$$z^{l+1} = \text{MSA}(\text{LN}(z^l)) + z^l$$

$$z^{l+1} = \text{MLP}(\text{LN}(z^{l+1})) + z^{l+1}$$

通过多层编码，模型可逐步提取图像的全局特征与局部细粒度特征。

## 3. 双分支学习（核心设计）

### （1）Global Branch（全局分支）

- 直接使用Transformer Encoder输出的CLS token作为全局特征表示；
- 核心作用：捕捉目标的全局上下文信息，用于整体匹配，确保模型对目标的整体特征有清晰认知。

### （2）Jigsaw Branch（拼图分支，关键创新）

- 对Patch Embedding后的patch序列进行shuffle和分组操作（即JPM模块）；
- 将处理后的patch序列输入共享的Transformer Encoder，提取局部特征；
- 核心作用：强化模型对局部特征的鲁棒性，捕捉目标的细粒度细节，弥补全局分支在局部建模上的不足。

👉 最终特征融合：将全局分支输出的全局特征（$$f_{global}$$）与拼图分支输出的局部特征（$$f_{local}$$）进行拼接，得到最终的目标特征表示：

$$f = [f_{global}, f_{local}]$$

# 四、损失函数

为实现精准的目标匹配，TransReID采用“分类损失+度量损失”的组合损失函数，兼顾分类准确性与特征相似度度量。

## 1️⃣ ID Loss（分类损失）

用于训练模型区分不同目标的ID，本质是交叉熵损失，公式如下：

$$\mathcal{L}_{id} = - \sum y \log p$$

其中，y为目标的真实ID标签，p为模型预测的ID概率分布，核心目标是让模型学习到能够区分不同ID的特征。

## 2️⃣ Triplet Loss（三元组损失，度量学习）

用于优化特征空间的距离分布，使同一ID的特征更集中、不同ID的特征更分散，公式如下：

$$\mathcal{L}_{tri} = \max(0, d(a,p) - d(a,n) + m)$$

其中，a为锚点样本，p为与a同ID的正样本，n为与a不同ID的负样本，d(·,·)表示特征之间的距离，m为margin（边界值）。

👉 核心目标： - 同ID样本的特征距离（d(a,p)）尽可能小； - 不同ID样本的特征距离（d(a,n)）尽可能大，且满足d(a,n) - d(a,p) ≥ m。

# 五、实验结果（核心结论）

作者在多个主流ReID数据集上进行了充分实验，验证了TransReID的性能优越性，涵盖行人和车辆ReID场景，具体如下：

## 1. 实验数据集

- 行人ReID：MSMT17、Market-1501、DukeMTMC-reID；
- 车辆ReID：VeRi-776；
- 此外，在另外3个数据集上也实现了SOTA性能，充分证明了模型的泛化能力。

## 2. 关键实验结论

- 性能超越现有CNN方法：TransReID在所有测试数据集上均达到SOTA水平，证明纯Transformer架构可有效替代CNN，在ReID任务中表现更优；
- 遮挡场景提升明显：得益于JPM模块的局部鲁棒性增强设计，模型在目标部分遮挡的场景下，匹配精度相较于CNN方法有显著提升；
- 跨摄像头鲁棒性更强：SIE模块有效缓解了跨摄像头偏差，使模型在不同摄像头的跨视角匹配任务中表现更稳定；
- 消融实验验证：单独加入JPM或SIE模块均能使模型性能稳定提升，二者结合可实现性能进一步突破，证明了两个创新模块的有效性；
- 预训练影响：基于ImageNet22K预训练的ViT，其迁移性能优于在ImageNet上预训练的DeiT，说明更大规模的预训练数据有助于提升模型的泛化能力；
- 注意力可视化：TransReID相较于CNN，能挖掘到更多目标的判别性区域，同时捕捉更全面的全局特征。

# 六、关键创新总结（面试/考试重点）

## ⭐ 1. 架构创新：纯Transformer替代CNN

- ReID领域**首个纯Transformer框架**，打破了对CNN backbone的依赖；
- 证明了ViT的全局建模和patch-level建模能力，完全适用于ReID的细粒度匹配与跨视角匹配需求。

## ⭐ 2. 模块创新：SIE（侧信息嵌入，非常重要）

👉 ReID领域经典创新思想，被后续众多研究借鉴： > **把camera ID、视角等非视觉信息当作embedding，与视觉特征融合，显式建模domain bias**，解决跨摄像头偏差问题，且设计简洁、通用性强。

## ⭐ 3. 模块创新：JPM（拼图补丁模块，核心技巧）

👉 本质是“数据增强+结构正则化”的结合，核心作用：

- 打乱patch的空间结构，强制模型学习位置不变特征；
- 强化模型的局部鲁棒性，弥补纯Transformer局部建模的不足；
- 提升模型对遮挡、姿态变化的适应能力和细粒度判别能力。

## ⭐ 4. 结构创新：Global + Local双分支融合

- CLS token（全局分支）→ 捕捉全局上下文特征；
- JPM模块（拼图分支）→ 捕捉局部细粒度特征；
- 二者互补，实现“全局+局部”的联合建模，兼顾匹配精度与鲁棒性。

# 七、论文局限与后续工作

## 1. 论文局限

- **计算开销大**：Transformer的自注意力机制计算复杂度高，相较于CNN，模型训练和推理速度较慢，不利于实际场景的部署；
- **数据依赖性强**：模型性能依赖大量标注数据，在小样本场景下泛化能力有限；
- **局部建模仍有不足**：纯Transformer天然偏全局建模，局部细节捕捉能力不如CNN，需依赖JPM模块弥补，结构上仍有优化空间。

## 2. 后续工作方向

针对上述局限，后续研究（如TE-TransReID）开始探索“Transformer + CNN混合结构”，结合二者优势：用CNN提取局部细粒度特征，用Transformer建模全局关系，在保证性能的同时降低计算开销、提升局部建模能力 。此外，后续还有研究提出UntransReID等基线模型，拓展了Transformer在无监督、跨模态ReID场景中的应用。

# 八、一句话总结

👉 **TransReID = ViT（纯Transformer架构） + SIE（跨摄像头偏差建模） + JPM（局部鲁棒性增强）**

本质思想： > 利用Transformer的全局建模能力，结合SIE和JPM两个创新模块，弥补纯Transformer在局部建模和偏差抑制上的不足，实现“全局+细粒度+上下文”的联合建模，最终突破传统CNN方法的性能瓶颈，推动ReID领域进入纯Transformer研究新阶段。

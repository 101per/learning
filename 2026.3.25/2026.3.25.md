# 一、从标准 Diffusion 出发（迁移基础）

你已经了解图像 diffusion，本质是：

------

## 前向过程（加噪）

q(x_t \mid x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t I)

逐步把数据 (x_0) 变成高斯噪声 (x_T)

------

## 反向过程（去噪）

[
p_\theta(x_{t-1} \mid x_t)
]

学习从噪声恢复数据

------

# 二、Diffusion Policy 的关键替换

现在做一个映射：

------

## 图像 diffusion → 动作 diffusion

| 图像 diffusion | Diffusion Policy        |
| -------------- | ----------------------- |
| (x)（图像）    | (a_{t:t+H})（动作序列） |
| pixel          | action                  |
| image          | trajectory              |

------

👉 核心替换：

[
x_0 \Rightarrow a_{t:t+H}
]

------

# 三、前向过程（作用在 action 上）

------

## 定义：

q(a^k \mid a^{k-1}) = \mathcal{N}(a^k; \sqrt{1-\beta_k} a^{k-1}, \beta_k I)

------

### 含义：

- (a^0)：真实 expert trajectory
- (a^k)：加入噪声后的动作
- (a^K)：完全随机动作

------

👉 直观理解：

```text
专家动作序列
→ 加噪
→ 更乱的动作
→ 完全随机动作
```

------

# 四、反向过程（模型学习的核心）

------

## 模型学习：

[
p_\theta(a^{k-1} \mid a^k, o_t)
]

------

### 输入：

- noisy action (a^k)
- 当前观测 (o_t)

------

### 输出：

- 更“干净”的 action

------

👉 本质：

> 学会：**“在当前观测下，如何把错误动作修正为合理动作”**

------

# 五、训练目标（最关键）

------

## 常用形式：预测噪声

\mathcal{L} = \mathbb{E}*{a^0, \epsilon, k} \left[ | \epsilon - \epsilon*\theta(a^k, o_t, k) |^2 \right]

------

## 变量解释：

- (a^0)：真实动作序列
- (\epsilon)：加的噪声
- (a^k)：带噪动作
- (\epsilon_\theta)：模型预测的噪声

------

## 本质：

> **让模型学会识别“哪些是噪声，哪些是正确动作结构”**

# 一、Diffusion 的数学推导（前向 / 反向 / 预测噪声）

我们从最标准形式推导，然后再对应到 action。

------

# 1️⃣ 前向过程（Forward Process）

目标：

> 把真实数据 (a^0) 逐步变成高斯噪声

------

## 定义（逐步加噪）

q(a^k \mid a^{k-1}) = \mathcal{N}(a^k; \sqrt{1-\beta_k} a^{k-1}, \beta_k I)

------

## 展开成一步形式（关键）

可以直接写成：

[
a^k = \sqrt{\alpha_k} a^{k-1} + \sqrt{1 - \alpha_k},\epsilon_k
]

其中：

- (\alpha_k = 1 - \beta_k)
- (\epsilon_k \sim \mathcal{N}(0, I))

------

## 推导到任意步（核心结论）

经过递推，可以得到：

[
a^k = \sqrt{\bar{\alpha}_k} a^0 + \sqrt{1 - \bar{\alpha}_k},\epsilon
]

其中：

[
\bar{\alpha}*k = \prod*{i=1}^k \alpha_i
]

------

## 这个式子的意义（非常重要）

> 任意时刻的 noisy action =
> “原始动作” + “高斯噪声”的线性组合

------

👉 这一步是整个 diffusion 成立的关键

------

# 2️⃣ 反向过程（Reverse Process）

目标：

> 学习从 (a^k) 还原 (a^{k-1})

------

真实分布：

[
q(a^{k-1} \mid a^k)
]

是**已知可解的高斯分布**（条件高斯）

------

但问题：

- 它依赖 (a^0)（未知）

------

👉 所以我们训练一个模型：

[
p_\theta(a^{k-1} \mid a^k, o_t)
]

------

## 参数化方式（关键设计）

不直接预测 (a^{k-1})，而是预测：

### 👉 噪声 (\epsilon)

------

# 3️⃣ 为什么要“预测噪声”？（核心推导）

我们有：

[
a^k = \sqrt{\bar{\alpha}_k} a^0 + \sqrt{1 - \bar{\alpha}_k},\epsilon
]

------

## 重排：

[
\epsilon = \frac{a^k - \sqrt{\bar{\alpha}_k} a^0}{\sqrt{1 - \bar{\alpha}_k}}
]

------

👉 如果模型能预测 (\epsilon)，就可以反推出：

[
a^0 = \frac{a^k - \sqrt{1 - \bar{\alpha}_k},\epsilon}{\sqrt{\bar{\alpha}_k}}
]

------

## 结论：

> **预测噪声 ≡ 预测原始数据**

------

# 4️⃣ 训练目标推导

------

## ELBO（略去细节）最终可化简为：

[
\mathcal{L} =
\mathbb{E}*{a^0, \epsilon, k}
\left[
|\epsilon - \epsilon*\theta(a^k, o_t, k)|^2
\right]
]

------

## 本质：

- 输入：noisy action
- 输出：预测噪声
- 优化：MSE

------

👉 关键点：

> 这是一个**简单监督学习问题**

------

# 5️⃣ 推理过程（严格表达）

从噪声开始：

[
a^K \sim \mathcal{N}(0, I)
]

逐步更新：

[
a^{k-1} =
\frac{1}{\sqrt{\alpha_k}}
\left(
a^k - \frac{1 - \alpha_k}{\sqrt{1 - \bar{\alpha}*k}} \epsilon*\theta(a^k)
\right)

- \sigma_k z
  ]

------

👉 本质：

> 每一步用模型“去掉一部分噪声”

------

# 二、时间一致性（Temporal Consistency）

你卡在这个点是正常的，这是 diffusion policy 的核心优势之一。

------

# 1️⃣ 问题背景

机器人动作：

[
a_{t:t+H} = [a_t, a_{t+1}, ..., a_{t+H}]
]

------

这些 action 必须满足：

- 平滑（smooth）
- 连续（continuous）
- 动力学可行（feasible）

------

# 2️⃣ Transformer / BC 的问题

如果逐点预测：

[
a_t = f(o_t)
]

那么：

- 每个时间步是**独立预测**
- 没有约束：

```text
a_t ≠ a_{t+1} 的关系
```

------

👉 会出现：

- 抖动（jitter）
- 不连续
- 不物理

------

# 3️⃣ Diffusion Policy 的做法

它建模的是：

[
p(a_{t:t+H})
]

------

## 关键点：

> **整个序列作为一个整体建模**

------

在去噪过程中：

- 每一步都在优化整个 trajectory
- 每个时间点都会影响其他点

------

👉 结果：

> 自动学到：

- 平滑性
- 时间依赖
- 动作结构

------

# 4️⃣ 本质总结

------

## 时间一致性 =

[
a_{t:t+H} \text{ 是一个结构化整体，而不是独立点}
]

------

## Diffusion 的优势：

```text
全局优化 trajectory
```

而不是：

```text
逐点预测
```

------

# 三、Diffusion vs Transformer（你问的关键问题）

------

# 1️⃣ Transformer 真的“更难学”吗？

不是本质原因，真正原因是：

------

## ❌ Transformer问题

[
a = f(o)
]

优化：

[
\min ||a - a^{expert}||
]

------

👉 会导致：

### 问题1：均值解（mode collapse）

如果有多种解：

```text
左手抓 / 右手抓
```

模型会学到：

```text
中间动作（错误）
```

------

### 问题2：one-shot prediction

- 一次输出
- 没有修正机制

------

# 2️⃣ Diffusion 的优势（本质）

------

## 优势1：逐步优化（iterative refinement）

```text
错误动作
→ 一步步修正
→ 正确动作
```

------

## 优势2：多模态建模

[
p(a) = \sum_i p_i(a)
]

------

## 优势3：更容易优化

因为：

> 任务变成：预测噪声（简单）

而不是：

> 直接预测复杂结构

------

# 3️⃣ 核心对比总结

------

## Transformer：

```text
一步到位预测答案
```

------

## Diffusion：

```text
从错误到正确逐步逼近
```

------

👉 类比：

- Transformer：考试直接写答案
- Diffusion：一步步改错直到正确

------

# 四、最终总结（你必须抓住的点）

------

## 行为层：

- 不是预测 action
- 而是**优化 action**

------

## 系统层：

- 天然支持多模态
- 天然保证时间一致性

# 一、两个“序列”的区别（必须先分清）

------

## 1️⃣ 时间维度（trajectory）

这是任务本身：

[
a_{t:t+H} = [a_t, a_{t+1}, ..., a_{t+H}]
]

- 表示未来一段动作
- **这是你要生成的目标**

------

## 2️⃣ diffusion 维度（noise level）

这是生成过程：

[
a^K \rightarrow a^{K-1} \rightarrow \dots \rightarrow a^0
]

- 表示从噪声到干净数据
- **这是生成的过程**

------

## ❗关键结论

> 你说的“这一整个序列”，指的是：
>
> [
> a_{t:t+H}
> ]
>
> **不是**
>
> [
> a^K \rightarrow a^0
> ]

------

# 二、Diffusion 是如何“一次优化整个序列”的？

------

## 1️⃣ 关键建模对象

Diffusion Policy 的变量是：

[
a^k \in \mathbb{R}^{H \times d}
]

也就是说：

- 一个 (a^k) 本身就是：

  ```text
  一个完整动作序列（trajectory）
  ```

------

## 2️⃣ 每一步去噪在做什么？

每一步：

[
a^{k-1} = \text{denoise}(a^k)
]

但注意：

- 输入 (a^k)：是整个序列
- 输出 (a^{k-1})：还是整个序列

------

👉 所以：

> **每一步都在“整体修改整个 trajectory”**

------

## 3️⃣ 更具体一点（非常重要）

假设：

[
a^k =
\begin{bmatrix}
a_t \
a_{t+1} \
a_{t+2}
\end{bmatrix}
]

------

模型输入：

```text
整个矩阵（序列）
```

模型输出：

```text
对整个矩阵的噪声预测
```

------

👉 结果：

```text
a_t 会受到 a_{t+1}, a_{t+2} 的影响
```

------

# BC是什么意思

BC 是 **Behavior Cloning（行为克隆）**，属于**模仿学习（Imitation Learning）**的一种最基础形式。

------

# 一、形式化定义

给定专家数据：

[
\mathcal{D} = {(o_t, a_t^{expert})}
]

学习一个策略：

[
\pi_\theta(a_t \mid o_t)
]

使其最小化：

[
\mathcal{L} = \mathbb{E}_{(o_t, a_t)} \left[ | a_t - a_t^{expert} |^2 \right]
]

------

# 二、直观理解

> **BC = 把策略学习问题转化为监督学习问题**

------

## 输入输出关系：

```text
输入：观测（图像 / 状态）
输出：动作（专家给的）
```

------

## 本质：

```text
看专家怎么做 → 学着做一样的
```

------

# 三、在机器人/VLA中的作用

BC 是最直接的策略学习方式：

------

## 例子：

数据：

```text
图像：桌子上有杯子
动作：机械臂移动到杯子上方
```

------

模型学习：

```text
看到类似图像 → 输出类似动作
```

------

# 四、BC 的优点

------

## 1️⃣ 简单稳定

- 不需要 reward
- 不需要 RL
- 训练就是标准 supervised learning

------

## 2️⃣ 数据效率高

- 不需要探索
- 直接用专家数据

------

如果：

```text

```

```text

```

# 一、统一问题定义（核心抽象）

我们要学习的是一个策略分布：

[
\pi(a_{t:t+H} \mid o_t, c)
]

其中：

- (o_t)：当前观测
- (c)：任务条件（语言等）
- (a_{t:t+H})：未来动作轨迹

------

## 两种“最优性定义”

关键分歧在这里：

------

### 1️⃣ 基于 reward 的最优性（RL）

[
\pi^* = \arg\max_\pi \mathbb{E}\left[\sum r\right]
]

------

### 2️⃣ 基于数据的最优性（Imitation）

[
\pi^* \approx p_{data}(a \mid o)
]

------

👉 结论：

> 所有方法的差别，本质是：
>
> **你用什么定义“好策略”**

------

# 二、统一三种方法

------

# 1️⃣ Behavior Cloning（BC）

------

## 目标：

[
\min_\theta \mathbb{E}*{(o,a)\sim \mathcal{D}} |a - \pi*\theta(o)|^2
]

------

## 等价形式：

[
\min D_{KL}(p_{data} \parallel \pi_\theta)
]

------

## 特点：

- 学的是：**条件均值（point estimate）**
- 输出：

[
a = \pi(o)
]

------

## 本质：

> **把分布压缩成一个点**

------

# 2️⃣ Diffusion Policy

------

## 目标：

[
\min D_{KL}(p_\theta(a_{t:t+H} \mid o) \parallel p_{data}(a_{t:t+H} \mid o))
]

------

## 实现方式：

通过 diffusion：

- 学习数据分布
- 逐步生成样本

------

## 特点：

- 学的是：**完整分布（distribution）**
- 输出：

[
a_{t:t+H} \sim p_\theta(\cdot \mid o)
]

------

## 本质：

> **不再压缩分布，而是重建分布**

------

# 3️⃣ Dreamer（Model-based RL）

------

## 目标：

[
\max_\pi \mathbb{E}_{z \sim f, a \sim \pi} \left[\sum r\right]
]

------

## 特点：

- 不学习数据分布
- 而是通过 reward 定义“好坏”

------

## 本质：

# BC把分布压在一个点不是很懂

我来用严格的概率和直观图像帮你理解 **“BC 把分布压成一个点”** 这个说法。

------

# 一、BC 的核心目标

BC（Behavior Cloning）是模仿学习，它的目标是**拟合专家行为**：

[
\pi_\theta(a \mid o) \approx p_{data}(a \mid o)
]

其中：

- (a)：动作
- (o)：观测
- (p_{data}(a \mid o))：专家的动作分布（真实存在的多种可能动作）

------

BC 的损失函数通常是**均方误差（MSE）**：

[
\mathcal{L}(\theta) = \mathbb{E}*{(o,a)\sim \mathcal{D}} \big[ | a - \pi*\theta(o) |^2 \big]
]

------

# 二、数学上为什么“压成点”

------

假设对于某个观测 (o)，专家在数据中表现出**多模态动作**：

[
a \in {a_1, a_2}
]

- 左手抓
- 右手抓

这时真实分布是：

[
p_{data}(a \mid o) = 0.5 \delta(a - a_1) + 0.5 \delta(a - a_2)
]

------

BC 损失优化的本质是：

[
\pi_\theta(o) = \arg\min_a \mathbb{E}*{a\sim p*{data}} | a - \pi_\theta(o) |^2
]

已知结论：

> MSE 最优解 = **条件期望**

[
\pi_\theta(o) = \mathbb{E}*{a \sim p*{data}}[a] = \frac{a_1 + a_2}{2}
]

------

## 解释：

- 数据分布有两种动作 (a_1, a_2)
- BC 学到的动作 = 两者平均
- 如果平均后的动作无法执行（比如左手 + 右手中间），就**不可行**

------

### 所以才说：

> BC 把分布压成一个点 = **只学到期望动作，不保留多模态**

------

# 三、直观类比

想象你要模仿一个专家画两条不同路径：

- 专家有两条可能的轨迹
- BC 学习后，模型输出的是 **两条轨迹的“平均轨迹”**
- 结果往往是一条“不自然”的路径

------

# 四、Diffusion Policy 是怎么解决的

------

Diffusion Policy 不输出一个点，而是**生成整个分布**：

[
a \sim p_\theta(a \mid o)
]

- 可以在左手抓、右手抓之间随机采样
- **保留多模态**
- 每次生成动作序列都可能不同，但都合理

------

# 五、总结一句话

- **BC** → 输出一个固定动作 = **压缩分布到一点**
- **Diffusion** → 输出动作分布 = **保留整个可能性空间**

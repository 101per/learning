# 今日推荐学习主题（核心）

## 一、Diffusion Policy（扩散策略模型）

这是目前连接 **Diffusion 与 Action / 控制 / VLA** 的最直接桥梁。

### 为什么必须学这个？

你当前的一个核心疑问是：

> diffusion 是一步步去噪，为什么能生成一整个 action 序列？

Diffusion Policy 正是在解决：

- 如何用 diffusion **直接生成动作序列**
- 如何替代传统 RL policy
- 为什么可以“一次优化整个序列”

------

## 需要重点掌握的内容

### 1. Action 作为序列建模对象

定义：

- 动作序列：
  [
  \mathbf{a}_{0:T} = (a_0, a_1, \dots, a_T)
  ]

传统 RL：
[
\pi(a_t | s_t)
]

Diffusion Policy：
[
p(\mathbf{a}_{0:T} | s_0)
]

👉 本质变化：

| 方法             | 建模方式         |
| ---------------- | ---------------- |
| RL / BC          | 单步决策         |
| Diffusion Policy | **整段轨迹建模** |

------

### 2. Forward Diffusion（作用在 action 上）

对整个动作序列加噪：

[
q(\mathbf{a}^k | \mathbf{a}^0) = \mathcal{N}(\sqrt{\alpha_k}\mathbf{a}^0, (1-\alpha_k)\mathbf{I})
]

符号解释：

- ( \mathbf{a}^0 )：真实动作序列
- ( \mathbf{a}^k )：第 k 步加噪后的动作
- ( \alpha_k )：衰减系数（控制信号强度）
- ( \mathcal{N} )：高斯分布

👉 含义：

- 动作逐渐被“破坏”
- 最终变成纯噪声序列

------

### 3. 反向过程（生成 action）

模型学习：

[
p_\theta(\mathbf{a}^{k-1} | \mathbf{a}^k, s)
]

通常转化为预测噪声：

[
\epsilon_\theta(\mathbf{a}^k, s, k)
]

------

### 4. Loss 函数（核心）

[
\mathcal{L} = \mathbb{E}*{k, \epsilon} \left[ | \epsilon - \epsilon*\theta(\mathbf{a}^k, s, k) |^2 \right]
]

解释：

- ( \epsilon )：真实噪声
- ( \epsilon_\theta )：模型预测噪声
- 本质：**最小二乘误差（MSE）**

👉 关键点：

- 模型不是直接预测 action
- 而是预测“如何去噪”

------

### 5. 为什么可以“一次生成整个序列”

核心原因：

- 输入：整个 noisy action sequence
- 输出：整个去噪方向

因此：

[
\mathbf{a}^{k-1} = f_\theta(\mathbf{a}^k, s)
]

👉 每一步更新的是**整个向量**

不是：

- ( a_0 \rightarrow a_1 \rightarrow a_2 )

而是：

- ( (a_0, a_1, ..., a_T) ) 一起更新

------

## 二、Time Consistency（时间一致性）

这是你之前问到但还没有完全打通的关键概念。

### 定义

生成的动作序列必须满足：

[
a_t \text{ 与 } a_{t+1} \text{ 在动力学上连续}
]

否则会出现：

- 抖动
- 不可执行动作
- 非物理轨迹

------

### Diffusion 为什么天然满足？

因为：

- 每一步都是小幅去噪（连续变化）
- 相邻时间步共享结构

👉 可以理解为：

> diffusion 在 trajectory space 中做“平滑路径搜索”

------

## 三、BC vs Diffusion Policy（必须搞清）

### BC（Behavior Cloning）

[
\mathcal{L}_{BC} = | a_t - \hat{a}_t |^2
]

问题：

- 单点学习
- 无全局规划能力
- 容易累积误差

------

### Diffusion Policy

[
\mathcal{L}*{diffusion} = | \epsilon - \epsilon*\theta |^2
]

优势：

- 建模整个分布
- 多模态（multi-modal）
- 可以生成多种合理轨迹

# Diffusion模型讲讲

# Diffusion模型详解

Diffusion模型（扩散模型）是当前生成式AI领域的核心技术之一，本质是一类基于概率的生成模型，核心思路源于物理中的扩散现象（如墨水滴入清水后逐渐散开），通过“逐步加噪-逆向去噪”的过程学习数据分布，最终实现从随机噪声生成高质量样本，目前已广泛应用于图像、音频等生成任务，Stable Diffusion、DALL·E 2等热门工具均基于其研发而来。

## 一、核心原理：模拟“破坏与重建”

Diffusion模型的运作核心分为两个互补的过程——前向加噪和反向去噪，类比来说，就像先把一幅清晰的画逐步涂成“雪花点”，再学习如何一步步把“雪花点”还原成完整的画，整个过程依托马尔可夫链（未来状态只依赖当前状态，与过去无关）展开。

### 1. 前向过程（逐步加噪，无需学习）

这个过程是固定的、预先定义好的，核心是将原始清晰数据（如图像）逐步转化为纯随机噪声。具体来说，会设定固定的加噪步数（通常为1000步），每一步都向上一步的样本添加少量高斯噪声，且加噪强度遵循预设的“噪声计划”——越往后的步骤，添加的噪声越多，样本的信噪比越低。经过全部步数后，原始数据会完全变成与原始信息无关的纯噪声，这个过程就像墨水滴入清水后，逐渐扩散至整杯水变得均匀浑浊一样，其核心作用是为后续反向去噪提供“学习素材”，记录下“如何弄脏样本”的全过程。

### 2. 反向过程（逐步去噪，核心学习部分）

这是模型需要重点学习的环节，目标是从纯随机噪声出发，逐步去除噪声，最终还原出清晰、真实的样本。由于前向加噪过程中会丢失信息，直接反转加噪过程难度极大，因此模型会训练一个神经网络（通常采用U-Net架构，擅长处理空间结构数据），专门预测每一步加噪时添加的噪声量。

神经网络的输入是当前步骤的噪声样本和对应的步骤编号（告知网络当前处于哪个去噪阶段），输出是对该步骤添加噪声的预测值；得到预测噪声后，通过特定数学公式“减去”噪声，就能估计出上一步更清晰的样本，重复这一过程，从纯噪声逐步还原，最终得到高质量的生成样本，就像倒放墨水扩散的过程，精准“收回”每一步扩散的墨水粒子。

## 二、训练过程：学会“精准去噪”

模型的训练核心是让神经网络学会精准预测噪声，具体流程简单可概括为四步：一是从训练数据集中随机抽取一张真实样本（如图像）；二是随机选择一个加噪步骤，直接计算出该步骤的噪声样本和实际添加的噪声；三是将噪声样本和步骤编号输入神经网络，得到预测噪声；四是计算预测噪声与实际噪声的差异（即损失），通过反向传播优化神经网络参数，反复迭代后，模型就能精准掌握每一步的去噪规律。

## 三、核心特点：优势与不足

### 1. 核心优势

相比传统生成模型（如GAN），Diffusion模型的优势十分突出：一是训练稳定，无需生成器与判别器的对抗博弈，只需专注于噪声预测，不会出现模式崩溃等问题，这也是工业应用中优先选择它的关键原因；二是生成质量高、多样性强，能还原丰富的细节，避免生成重复内容；三是可控性强，支持文本、草图等多条件引导，通过ControlNet、LoRA等技术，可精准控制生成内容的风格、姿态等；四是可解释性强，前向加噪和反向去噪过程清晰，不像GAN那样属于“黑盒模型”。

### 2. 主要不足

其最大的短板是推理速度慢，由于需要几十到上百步的迭代去噪，传统模型生成一张图像可能需要20分钟，虽然后续DPM-Solver等算法将步骤压缩至10步以内，速度大幅提升，但仍慢于GAN；此外，训练和推理的算力需求较高，处理高清样本时显存消耗大，难以用于实时生成场景（如游戏实时渲染）。

## 四、发展与应用

Diffusion模型于2015年首次提出，但未受到广泛关注；2020年Google推出DDPM框架，奠定了现代扩散模型的基础，首次在图像生成任务中超越GAN；2022年Stable Diffusion通过潜在空间压缩技术，大幅降低计算成本，引发AI艺术创作热潮；如今已拓展到多领域应用。

其核心应用包括：图像生成（文生图、图生图，如Midjourney生成艺术作品）、图像修复与扩展（填补老照片划痕、扩展图像边界）、超分辨率（将模糊图像提升至高清）、音频合成（生成音乐、语音），以及医学领域（生成MRI影像辅助诊断）、材料科学（模拟分子扩散）等跨学科场景。

总结来说，Diffusion模型通过“化繁为简”的思路，将复杂的生成任务拆解为多步简单的去噪任务，凭借稳定、高质量的优势，成为当前AIGC的主流框架，未来随着加速算法和轻量化技术的发展，其应用场景还将进一步拓展。

# 一、Diffusion 的核心思想（抓住这3点就够）

## 1. 正向过程：逐步加噪（Forward Process）

- 从真实数据 (x_0) 出发
- 一步步加高斯噪声 → 最终变成纯噪声 (x_T)

直觉：

> 把一张清晰图像“腐蚀”成白噪声

------

## 2. 反向过程：逐步去噪（Reverse Process）

- 学一个模型（通常是 U-Net）
- 输入 noisy image → 预测“如何去噪”
- 一步步还原图像

直觉：

> 学会“如何从噪声中恢复结构”

------

## 3. 学习目标（关键本质）

不是直接生成图像，而是：

> **学习噪声分布（denoising / score）**

常见形式：

- 预测噪声 ε（最常见）
- 预测原图 x₀
- 预测 score（梯度）

------

# 二、Diffusion 三大主流建模视角（非常关键）

这三类本质**等价**，但理解角度不同：

## 1. DDPM（Denoising Diffusion Probabilistic Model）

最经典、最工程实用

特点：

- 离散时间（t = 1...T）
- 马尔可夫链
- 逐步去噪

代表：

- DDPM（Ho et al. 2020）

👉 工程上：**Stable Diffusion 就是这一系**

------

## 2. Score-based Model（Score Matching）

更理论化

核心：

- 学习 ∇ log p(x)（概率密度梯度）

理解：

> 告诉你“往哪个方向走更像真实数据”

------

## 3. SDE / ODE 视角（连续化）

把 diffusion 看成连续时间过程

- SDE（随机微分方程）
- ODE（确定性生成）

代表：

- DDIM（ODE）
- Score SDE

------

# 三、三个核心模块（逐个拆）

------

## 1️⃣ Text Encoder（文本理解）

典型：CLIP Text Encoder

👉 作用：

> 把文本变成“语义向量”

例子：


这个向量：

- 不生成图像
- 只作为“条件控制信号”

## 2️⃣ VAE（潜空间压缩）【关键】

### 为什么要 VAE？

如果直接在图像上做 diffusion：

- 分辨率高（512×512×3）
- 计算爆炸 💥

------

### 解决方案：

> **先压缩 → 在 latent 上做 diffusion**

------

### VAE 做两件事：

#### (1) Encoder

```
图像 → latent（压缩）
```

#### (2) Decoder

```
latent → 图像（还原）
```

------

### 关键理解：

- latent ≈ “低维图像表示”
- diffusion 不是在像素空间做，而是在 latent 空间做

👉 这就是：

> **Latent Diffusion（最大工程突破）**

------

## 3️⃣ Diffusion（核心生成器）

### 输入：

- noisy latent（z_t）

### 输出：

- 预测噪声 ε

### 结构：

# 四、Diffusion 在做什么（工程视角）

------

## 训练阶段：

### 过程：

1. 取真实图像
2. VAE → latent
3. 加噪声（随机 t）
4. 模型预测噪声 ε
5. loss = 预测 vs 真实噪声

------

👉 本质：

> 学会“如何去噪”

------

## 推理（生成）阶段：

### 过程：

1. 随机初始化：

```
z_T ~ N(0,1)
```

1. 循环去噪：

```
for t = T → 0:
    z_t → z_{t-1}
```

1. 得到：

```
z_0（干净 latent）
```

1. VAE decode → 图像

------

------

## 思想：

训练时：

- 有条件（text）

## 推理时：

# 一、为什么 diffusion 用 U-Net，而不是普通 CNN？

## 1️⃣ diffusion 的任务本质决定结构需求

diffusion 每一步做的是：

> **输入 noisy 图像 → 输出“去噪结果”（或噪声）**

这个任务有两个关键要求：

### （1）需要精细的空间信息（像素级）

- 每个像素都要恢复
- 不能丢细节

### （2）需要全局语义

- 图像整体结构（人脸、物体位置）
- 文本条件（prompt）

------

👉 结论：

> **既要“局部细节”，又要“全局语义”**

------

## 2️⃣ 普通 CNN（ResNet 等）的问题

典型 CNN：

- 一路下采样（分辨率越来越低）
- 最后只保留语义特征

👉 问题：

- ❌ 空间信息丢失
- ❌ 无法精细重建图像

------

## 3️⃣ U-Net 的关键设计（为什么完美匹配）

U-Net 结构：

```text
Encoder（下采样） → Bottleneck → Decoder（上采样）
            ↘ skip connection ↗
```

------

### 🔴 核心机制：Skip Connection

作用：

> **把“高分辨率细节”直接传给解码器**

------

### 带来的效果：

| 能力     | 来源            |
| -------- | --------------- |
| 全局语义 | encoder 深层    |
| 局部细节 | skip connection |
| 重建能力 | decoder         |

------

👉 本质：

> **U-Net = 语义理解 + 精细重建 的统一结构**

------

## 4️⃣ 为什么特别适合 diffusion

diffusion 每一步都在做：

```text
模糊图 → 稍微清晰一点的图
```

这本质是：

> **一个“图像到图像（image-to-image）任务”**

------

而 U-Net：

- 最早就是为 segmentation / 医学重建设计
- 天然适合：
  - denoising
  - super-resolution
  - inpainting

------

👉 关键结论：

> **U-Net 是最适合“逐步重建图像”的 CNN 结构**

------

## 5️⃣ 额外增强：Attention

在 Stable Diffusion 中：

- U-Net + self-attention
- - cross-attention（接文本）

👉 弥补 CNN 的缺点：

- 提供全局建模能力

# 一、AdaLN（Adaptive LayerNorm）— DiT 的核心控制机制

## 1️⃣ 先看 LayerNorm 在干什么

标准 LayerNorm：

```text
y = (x - μ) / σ * γ + β
```

- μ, σ：归一化
- γ, β：可学习参数

------

## 2️⃣ AdaLN 的核心变化

> **γ 和 β 不再是固定参数，而是由“条件”动态生成**

```text
γ = f(condition)
β = f(condition)
```

------

## 3️⃣ 在 diffusion / DiT 里，condition 是什么？

通常是：

- timestep（t）
- text embedding（prompt）
- class / 控制信号

------

## 4️⃣ 直觉理解（非常重要）

> **AdaLN = 用条件“调制整个网络的行为”**

而不是：

- 拼接输入 ❌
- 做 cross attention ❌

------

## 5️⃣ 为什么它重要

相比 cross-attention：

- 更轻量
- 更统一（所有条件都能进来）
- 更适合 Transformer

------

👉 一句话：

> **AdaLN 是 DiT 里“控制生成”的核心接口**

# 二、Flow 是什么（核心概念）

这是你必须建立的一个新视角。

------

## 1️⃣ diffusion 在干什么（回顾）

```text
噪声 → 一步步去噪 → 图像
```

------

## 2️⃣ Flow 的视角

> **Flow = 定义一个“连续变换路径”，把噪声变成数据**

------

用更直白的话：

```text
z(0) = 噪声
z(1) = 图像

中间：
z(t) 一条连续路径
```

------

👉 关键点：

- diffusion：离散步骤（t=1000,999,...）
- flow：连续变化（t ∈ [0,1]）

------

## 3️⃣ 数学本质（只看形式）

Flow 定义一个“速度场”：

```text
dz/dt = v(z, t)
```

# 三、Flow Matching 是什么

------

## 1️⃣ 核心思想

> **直接学习这个“速度场 v(z,t)”**

而不是：

- 学噪声（diffusion）
- 学 score（score model）

------

## 2️⃣ 和 diffusion 对比

| 方法          | 学什么    |
| ------------- | --------- |
| diffusion     | 噪声 ε    |
| score model   | ∇log p(x) |
| Flow Matching | 速度 v    |

------

👉 本质：

> **换了一个学习目标**

------

## 3️⃣ 为什么更简单

diffusion：

- 多步
- 复杂调度（noise schedule）

Flow Matching：

- 直接拟合路径
- 更“干净”的目标

------

# 四、Rectified Flow（为什么更重要）

这是目前更关键的方向。

------

## 1️⃣ Flow Matching 的问题

普通 flow：

- 路径可能很弯
- 不好学
- 不稳定

------

## 2️⃣ Rectified Flow 的核心改进

> **把路径“拉直”**

------

### 原本路径（diffusion）：

```text
噪声 → 曲折路径 → 图像
```

------

### Rectified Flow：

```text
噪声 → 直线 → 图像
```

------

👉 直觉：

> **走直线总比绕路容易**

------

## 3️⃣ 带来的好处

- 更稳定
- 更容易训练
- 更少步骤

------

# 五、为什么它们可能替代 diffusion

核心原因只有三个：

------

## 1️⃣ 采样速度（最关键）

diffusion：

- 需要几十~上百步

------

Flow / Rectified Flow：

- 可以做到：
  - 几步
  - 甚至一步（趋势）

------

👉 工业意义：

> **更快 = 更便宜 = 更可用**

------

## 2️⃣ 训练目标更直接

diffusion：

- 间接目标（预测噪声）

------

Flow：

- 直接学“怎么变”

------

👉 更接近“真实生成过程”

------

## 3️⃣ 更适合 Transformer

Flow：

- 本质是函数拟合

```text
v(z,t)
```

非常适合：

- DiT
- 多模态统一模型

------

# 六、你必须建立的统一理解

把三种方法统一起来看：

------

## diffusion

```text
学：怎么去噪
```

------

## score model

```text
学：往哪里更像数据
```

------

## flow

```text
学：应该往哪里移动
```

------

👉 本质统一：

> **都在学习“如何从噪声走到数据”**

------

# 七、当前趋势（非常关键）

2025+ 的方向：

- diffusion ✅（仍主流）
- DiT + diffusion ✅
- **Flow / Rectified Flow 🚀（强趋势）**

------

很多新模型正在：

> **从 diffusion → flow 迁移**

------

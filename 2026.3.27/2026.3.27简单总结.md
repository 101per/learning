**Q1：为什么 ( z = f(o) ) 可以替代真实状态 ( s )**

你的核心理解方向是对的，但需要提升到“决策充分性”的层面，而不是简单“低维表达”。

更严格地说：

观测 ( o \in \mathbb{R}^{H \times W \times 3} ) 是高维像素，它包含大量与决策无关的信息（背景、光照、纹理等）。通过视觉编码器：

[
z = f(o), \quad z \in \mathbb{R}^d
]

得到一个语义表示。

关键条件不是“降维”，而是满足：

[
p(a \mid o) \approx p(a \mid z)
]

这意味着：

- 用 ( z ) 做决策，与直接用 ( o ) 做决策是等价的
- 因此 ( z ) 是关于动作决策的**充分统计量（sufficient statistic）**

所以严格结论是：

- ( z \neq s )（不是物理真实状态）
- 但 ( z ) 是“对决策而言足够的状态表示”

本质：
视觉 encoder 学的不是“还原世界”，而是“提取对动作有用的信息”。

------

**Q2：语言如何改变动作分布**

你的直觉“语言决定哪条轨迹好”是对的，但需要用“分布变形”的语言来表达。

首先，语言经过编码：

[
c = f(l)
]

原始动作分布是：

[
p(\mathbf{a}_{0:T} \mid z)
]

加入语言后变为：

[
p(\mathbf{a}_{0:T} \mid z, c)
]

关键点：

语言的作用不是生成动作，而是**改变概率分布的形状**。

从能量模型角度：

[
p(\mathbf{a} \mid z, c) \propto \exp\big(R(\mathbf{a}, z, c)\big)
]

这里：

- ( R(\mathbf{a}, z, c) )：表示轨迹与任务（语言）的匹配程度

因此：

- 语言通过 ( c ) 改变 reward landscape
- 从而提升“符合指令”的轨迹概率
- 压低“不符合任务”的轨迹

更精确表达应是：

> 语言通过 conditioning 改变 ( p(\mathbf{a}) ) 的概率密度，而不是直接输出动作。

我们从最核心的问题开始：

为什么可以把“任务目标 / reward”加到 diffusion 里，并得到

[
p(\mathbf{a}) \propto \exp(R(\mathbf{a}))
]

或者更准确地说，为什么会出现

[
p(\mathbf{a}\mid \text{task}) \propto p(\mathbf{a}) \exp!\left(\frac{1}{\lambda}R(\mathbf{a})\right)
]

这里我先说明符号。

(\mathbf{a}) 表示整条动作轨迹，写成

[
\mathbf{a} = \mathbf{a}_{0:T} = (a_0,a_1,\dots,a_T)
]

其中 (a_t) 是第 (t) 个时刻的动作。

(R(\mathbf{a})) 表示这条轨迹的 reward，也就是“这条轨迹有多好”。

(\lambda>0) 是温度参数。它控制 reward 对分布的影响强度。
(\lambda) 越小，reward 的影响越强；(\lambda) 越大，reward 的影响越弱。

(p(\mathbf{a})) 表示“原始数据分布”，也就是不考虑额外任务偏好时，真实世界中合理轨迹本身的分布。

现在开始正式推导。

第一步，先定义一个“成功事件”。

我们引入一个随机变量 (y)，其中

[
y=1
]

表示“这条轨迹满足任务”或者“这条轨迹是成功的”。

那么我们真正想要的，不是原始分布 (p(\mathbf{a}))，而是满足任务条件后的后验分布：

[
p(\mathbf{a}\mid y=1)
]

这句话的意思是：

在所有轨迹里，我们只关心那些“成功完成任务”的轨迹，这时轨迹的概率分布会变成什么样。

接下来用贝叶斯公式。贝叶斯公式写成：

[
p(\mathbf{a}\mid y=1)=\frac{p(y=1\mid \mathbf{a})p(\mathbf{a})}{p(y=1)}
]

这个式子里：

(p(y=1\mid \mathbf{a})) 表示：给定轨迹 (\mathbf{a})，它成功的概率是多少。

(p(\mathbf{a})) 表示：这条轨迹本身在数据中有多自然、多常见。

(p(y=1)) 是归一化常数，它与 (\mathbf{a}) 无关，只是为了保证总概率积分为 1。

因为 (p(y=1)) 与 (\mathbf{a}) 无关，所以我们常写成比例关系：

[
p(\mathbf{a}\mid y=1)\propto p(y=1\mid \mathbf{a}),p(\mathbf{a})
]

这个式子非常关键，它告诉你：

任务条件后的轨迹分布 = 原始合理轨迹分布 × 任务成功偏好。

这一步就是 classifier guidance / reward guidance 的总根源。

现在第二步，把“成功概率”写成 reward 的指数形式。

为了把 reward 放进概率模型里，我们通常做如下假设：

[
p(y=1\mid \mathbf{a}) \propto \exp!\left(\frac{1}{\lambda}R(\mathbf{a})\right)
]

这个假设的含义是：

reward 越高，成功概率越大；并且这种关系用指数函数表示。

为什么用指数函数？因为它有三个很好的性质。

第一，它总是正数，适合作为概率的未归一化形式。
第二，它把“加法 reward”变成“乘法权重”，便于和概率分布结合。
第三，它在最大熵控制、control as inference、能量模型里都会自然出现。

把这个式子代回刚才的贝叶斯公式：

[
p(\mathbf{a}\mid y=1)\propto p(\mathbf{a})\exp!\left(\frac{1}{\lambda}R(\mathbf{a})\right)
]

这就是你想看到的核心式子。

如果把 “task” 直接记成条件变量 (c)，也可以写成：

[
p(\mathbf{a}\mid c)\propto p(\mathbf{a})\exp!\left(\frac{1}{\lambda}R(\mathbf{a},c)\right)
]

这里 (R(\mathbf{a},c)) 表示“轨迹 (\mathbf{a}) 在任务 (c) 下的得分”。

现在第三步，推到 score，也就是 diffusion 真正要用的东西。

diffusion 并不是直接操作 (p(\mathbf{a}))，而是操作它的对数梯度：

[
\nabla_{\mathbf{a}}\log p(\mathbf{a})
]

这里符号 (\nabla_{\mathbf{a}}) 表示“对轨迹变量 (\mathbf{a}) 求梯度”。

梯度的意思是：在轨迹空间中，往哪个方向移动，概率密度增长得最快。

我们现在对条件分布取对数。由

[
p(\mathbf{a}\mid c)\propto p(\mathbf{a})\exp!\left(\frac{1}{\lambda}R(\mathbf{a},c)\right)
]

得到

# [ \log p(\mathbf{a}\mid c)

\log p(\mathbf{a})
+
\frac{1}{\lambda}R(\mathbf{a},c)
+
\text{const}
]

这里 (\text{const}) 表示与 (\mathbf{a}) 无关的常数。因为比例关系取对数后，会多出一个归一化常数的对数；但它不依赖 (\mathbf{a})。

接着对 (\mathbf{a}) 求梯度：

# [ \nabla_{\mathbf{a}}\log p(\mathbf{a}\mid c)

\nabla_{\mathbf{a}}\log p(\mathbf{a})
+
\frac{1}{\lambda}\nabla_{\mathbf{a}}R(\mathbf{a},c)
]

这就是最重要的一步。

这个公式的含义是：

条件分布的 score
= 原始数据分布的 score

- reward 的梯度项。

也就是说，guidance 的本质不是“重新训练一个全新的分布”，而是：

在原本“自然轨迹”的上升方向上，再叠加一个“更高 reward”的上升方向。

这就是为什么很多论文会说：

guidance = score correction

或者说

guided score = base score + guidance term

现在第四步，把它连接到 diffusion 的噪声预测形式。

在 score-based diffusion / DDPM 中，模型虽然表面上预测的是噪声 (\epsilon_\theta)，但本质上对应的是 score：

[
s_\theta(\mathbf{x}*t,t) \approx \nabla*{\mathbf{x}_t}\log p_t(\mathbf{x}_t)
]

这里我把变量写成 (\mathbf{x}_t)，因为 diffusion 的第 (t) 步是“加噪时间步”，不是轨迹中的物理时间。
为避免混淆，你可以把这个 (t) 理解成 diffusion step。

(\mathbf{x}_t) 表示加噪后的轨迹样本。

在高斯噪声参数化下，有一个标准关系：

# [ s_\theta(\mathbf{x}_t,t)

-\frac{1}{\sigma_t}\epsilon_\theta(\mathbf{x}_t,t)
]

更严格地说，不同论文参数化略有常数差异，但本质都是：

预测噪声 (\epsilon_\theta) 和预测 score 是等价的，只差一个与噪声尺度有关的比例系数。

因此，如果我们已经知道

# [ \nabla_{\mathbf{x}_t}\log p(\mathbf{x}_t\mid c)

\nabla_{\mathbf{x}_t}\log p(\mathbf{x}*t)
+
\frac{1}{\lambda}\nabla*{\mathbf{x}_t}R(\mathbf{x}_t,c)
]

那么在 diffusion 采样时，就可以把原模型的 score 改成：

# [ s_{\text{guided}}(\mathbf{x}_t,t,c)

s_\theta(\mathbf{x}*t,t)
+
w,\nabla*{\mathbf{x}_t}R(\mathbf{x}_t,c)
]

这里 (w) 是指导强度，通常等价于某种 (1/\lambda) 的缩放，实际实现时也可能额外再乘一个手工超参数。

这一步的含义是：

原本 diffusion 每一步都在把样本往“更像训练数据”的方向推。
现在你再加一个梯度，把样本往“reward 更高”的方向推。
两者合起来，样本就会同时满足：

第一，像真实轨迹；
第二，任务得分高。

这就是 Diffuser 里 reward guidance 的数学本质。

现在第五步，解释为什么这不会直接把轨迹搞坏。

因为如果你只最大化 reward，也就是只用

[
\nabla_{\mathbf{a}}R(\mathbf{a},c)
]

那模型可能会走向一些“高 reward 但不自然”的区域。换句话说，它会脱离数据分布的 support。

这里的 support 可以理解成：

训练数据真正覆盖到、模型真正学会的那些合理轨迹区域。

所以真正合理的目标不是只做

[
\max_{\mathbf{a}} R(\mathbf{a},c)
]

而是做一种折中：

[
\max_{\mathbf{a}}
\left[
\log p(\mathbf{a})+\frac{1}{\lambda}R(\mathbf{a},c)
\right]
]

第一项 (\log p(\mathbf{a})) 保证轨迹自然、可行、在数据支持域内。
第二项 (R(\mathbf{a},c)) 保证轨迹朝任务目标优化。

因此，Diffuser / guidance 的真正思想可以概括为：

不是脱离数据分布去做暴力优化，
而是在数据分布内部，沿着 reward 更高的方向重新加权与采样。

现在第六步，我把整条逻辑链压缩成一句“论文级表达”。

原始轨迹分布为

[
p(\mathbf{a})
]

引入任务成功变量 (y=1) 后，条件分布满足

[
p(\mathbf{a}\mid y=1)\propto p(\mathbf{a})p(y=1\mid \mathbf{a})
]

若进一步假设成功概率满足 Boltzmann 形式

[
p(y=1\mid \mathbf{a})\propto \exp!\left(\frac{1}{\lambda}R(\mathbf{a})\right)
]

则得到

[
p(\mathbf{a}\mid y=1)\propto p(\mathbf{a})\exp!\left(\frac{1}{\lambda}R(\mathbf{a})\right)
]

对其取对数并求梯度，得到 guided score decomposition：

# [ \nabla_{\mathbf{a}}\log p(\mathbf{a}\mid y=1)

\nabla_{\mathbf{a}}\log p(\mathbf{a})
+
\frac{1}{\lambda}\nabla_{\mathbf{a}}R(\mathbf{a})
]

因此，在 diffusion 中可以通过向 base score 添加 reward gradient，实现任务引导采样。

最后我给你一个最直观的解释。

把 (\log p(\mathbf{a})) 想成“地形中的自然山谷结构”，它决定什么轨迹像真实数据。
把 (R(\mathbf{a})) 想成“任务目标的额外势能场”，它决定什么轨迹更有用。
那么 guidance 就是在两个场叠加之后，沿着新的总梯度上升或采样。

也就是：

“既要像真实数据，又要完成任务”。

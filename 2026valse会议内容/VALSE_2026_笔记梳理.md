# VALSE 2026 会议笔记内容梳理

> **会议**：VALSE 2026（视觉与学习青年学者研讨会）  
> **主题方向**：开放世界目标检测、跨模态统一建模、三维重建与空间智能、世界模型与具身智能

---

## 一、大模型驱动的开放世界目标检测

### 1.1 研究路径演进

| 阶段 | 名称 | 核心特征 |
|------|------|----------|
| **传统** | 开放世界目标检测 | 以检测为核心，显式发现未知目标，通过增量学习将未知转化为已知；具备发现未知类别、增量学习扩展等能力 |
| **传统** | 开放词汇目标检测 | 利用文本指示将固定标签空间扩展为开放语义空间，实现文本驱动的目标检测、任意类别零样本泛化 |
| **大模型时代** | 通用开放世界目标检测 | 以多模态大模型的生成与推理能力为核心，将目标检测扩展到图像、视频、3D场景与具身交互；具备多模态理解、复杂推理、交互式定位等能力 |

### 1.2 三大研究范式

**范式一：语义先验注入**
- 引入 LLM/VLM 生成的属性、类别与语义关系
- 增强开放类别识别能力
- 流程：文本 → LLM/VLM → 属性/类别/关系（语义先验）→ 注入检测器

**范式二：任务定制模型**
- 围绕任务特点设计专门架构
- 提升开放场景中的目标检测泛化能力
- 关键模块：视觉编码器、提示编码器、多任务解码器、记忆传播、几何融合

**范式三：VLM 原生定位对齐**
- 将目标框、掩码等转化为可生成输出
- 支撑指令驱动的目标检测
- 技术：VLM + 多模态编码器 + 定位对齐（SFT / RL / CoT）

**支撑基础**：大规模开放数据  
针对开放世界感知与理解需求，构建大规模多模态数据集（文本、图像、视频、深度图）。

## 二、跨模态推理范式：Agentic vs Unified

### 2.1 统一模型（Unified Model, UM）的优势

**为什么要 Unified 而非 Agentic？**
- **联合建模**：跨模态依赖可以被联合建模；Agentic systems 很难自然建模所有模态的联合分布
- **内在化推理**：Agentic 通过编排外部工具调用来实现推理；UM 构造模态的共享表示空间以内在化跨模态推理
- **端到端扩展性**：UM 的能力可随 model size + data scale + multimodal context 的扩展而持续提升，更接近 foundation model 的 scaling 路线
- **发展路径**：大语言模型的发展路径是 agent 能力内化到基础模型；统一建模是终局牵引，推动智能上限

### 2.2 视觉表示的核心问题

Unified Model 需要什么样的视觉表示？
- **像素重建 vs 语义对齐**
- **连续 vs 离散**

### 2.3 面向语义对齐的隐空间离散视觉表示（MBAQ）

- **发现**：这种表示可以恢复出原图中大部分像素信息
- **优势**：对于语义信息（如文字）的保留相比像素重建的特征更好，对跨模态推理十分重要
- **对比**：原图 → MBAQ（语义对齐量化）→ 像素空间 VQ
- **意义**：基于统一模型进行跨模态推理与世界建模的关键表示方法

## 三、三维重建与空间智能

### 3.1 几何基础

**相机投影模型（Pinhole Camera）**
- 核心转换：将三维世界坐标映射至二维像素平面
- 涉及内参矩阵 K 与外参矩阵 [R|t]

**多视图几何约束**
- **对极约束**：限制搜索范围至对极线
- **三角化**：已知位姿，通过多视图光线交点恢复 3D 坐标

### 3.2 传统三维重建流程及其局限

**传统流程**：
1. 位姿与稀疏点云求解（SfM）
2. 稠密深度计算（MVS）
3. 点云融合与网格提取（Fusion & Poisson Reconstruction）
4. 同时定位与建图（SLAM）

**核心局限**：
- 流程长，误差累计，不鲁棒
- 人为设计先验，不可靠
- 渲染效果差，对几何精准性敏感
- 网格表达难以表示复杂几何对象及纹理

### 3.3 3D 高斯泼溅（3D Gaussian Splatting, 3DGS）

**核心思想**：从隐式场向显式粒子的回归
- SFM 初始化后，生成具有方向性的小球簇
- 使用三维高斯分布函数刻画
- 可微属性分解（保证渲染中可逆变换）
- **优势**：显式辐射场、极速渲染

**前馈式高斯泼溅（Feedforward 3DGS）**
- **核心原理**：从"场景优化"转向"参数回归"
- **特征**：端到端属性回归；无需逐场景优化（从小时级降至毫秒级）
- **关键技术**：
  - 对极 Transformer（Epipolar Transformer）
  - 属性残差学习
  - 各向异性约束
  - 跨视图几何一致性
- **代表性工作（2024-2025）**：pixelSplat、MVSplat、NoPoSplat、GPS-Gaussian、LGM、AnySplat

**近期进展**：
- **AnySplat (2025)**：无需相机姿态，引入几何大模型先验
- **PhysGM (2026)**：同时建模物理属性

**NeRF vs 3DGS**：Modern3D 的趋势是从优化走向学习

### 3.4 基于神经网络的前馈式三维重建与渲染技术路线

| 技术方向 | 特征 | 黄金期/代表工作 |
|----------|------|----------------|
| **单目几何** | 从相对深度到物理尺度点云，从小模型到大模型大数据驱动 | 2023-2024: Depth Anything, Metric3D, Marigold, GeoWizard |
| **点云图重建** | 跳过相机内外参与显式几何先验，网络直接回归点云图 | 2024-2025: DUSt3R, MASt3R, VGGT, PI3, LingBot-Map |
| **前馈式 3DGS** | 前馈网络预测高斯属性，实现新场景零训练、毫秒级渲染 | 2023-2025: pixelSplat, MVSplat, LGM, AnySplat |
| **泛化式 NeRF** | 多视图特征插值输入 MLP，解决 NeRF 无法泛化的问题 | 2021-2022: PixelNeRF, IBRNet, MVSNeRF |
| **深度多目 (Deep MVS)** | 引入平面扫描，从 3D 卷积向轻量化演进 | 2018-2022: MVSNet, CasMVSNet, PatchMatchNet |
| **深度双目 (Deep Stereo)** | 沿极线搜索，引入代价体 (cost volume) | 2016-2018: GC-Net, PSMNet |

### 3.5 单目几何与点云图重建

**单目几何（Monocular Depth/Geometry）**
- **近期工作**：混合大数据、ViT 大模型（DINOv2 预训练）、Zero-shot 通用深度感知
- **代表工作**：Depth Anything v2 (2024)、Marigold (2024)、GeoWizard、MoGe、UniK3D
- **2026 视角总结**：
  - **基石先验**：零样本泛化（Zero-shot Everything）、全场景即插即用、公制尺度预测、数据驱动的物体先验
  - **细节几何精度极限提升**：像素级几何边界、薄壁拓扑完美理解、3DGS 与 Mesh 重建的初值精度

**点云图重建（PointMap Reconstruction）**
- **核心思想**：跳过相机内外参，跳过显式几何先验，网络直接回归点云图
- **大一统范式（Grand Unified Paradigm）**：PointMap 依赖，直接回归点云图，还能反推位姿、生成深度图、初始化 3DGS，已成为 3D 视觉通用底层表征
- **实时化与端侧化**：硬件加速下，可实现秒级"首扫重建"
- **代表性工作**：
  - **DUSt3R (2024)**：彻底抛弃管线，无需相机位姿/内参，一阶 ViT 回归
  - **MASt3R (2025)**：显式匹配分支，更高精度与锐度
  - **VGGT (2025)**：几何基础大模型，规模化预训练，通用 Zero-shot
  - **PI3 (2025)**：无需指定参考图，跨视图点对点精配
  - **LingBot-Map (2026)**：长序列流式建模，时序上下文 Transformer

**自回归 vs Diffusion**：自回归的优势是可以每一步去校正，具备实时性。

## 四、世界模型与实时生成

### 4.1 世界模型

**Matrix-Game 2.0：实时自回归**
- 和 GameFactory 类似的信号控制
- 完整的 Self-Forcing 流程
- 开源实时流式交互世界模型

**minWM（开源模型）**
- 首个覆盖数据、训练、蒸馏、推理全流程的 Action-conditioned World Model 开源框架
- 支持多个模型生态拓展

### 4.2 三维生成范式

**VecSet VAE 范式：CLAY**
- 支持多种条件输入：Image/Sketch、Voxel、Multiview Image、Sparse Point Cloud、Bounding Box、Partial Point Cloud
- 在隐空间上使用 DiT 做标准扩散生成
- 条件通过交叉注意力注入

**稀疏体素范式：Trellis2**
- **问题**：使用点云和隐式场作为中间表示可能损失精度
- **O-Voxel**：类似于像素中的 RGB，在体素中存储属性以恢复物体的几何和材质
- **突破**：不再限定于水密网格，生成网格不再必须依赖隐式场
- **稀疏体素**：只关注物体表面附近体素，并非所有体素都有信号

### 4.3 三维场景生成

**ViewCrafter**
- **目标**：打破密集视角依赖，利用视频扩散模型从稀疏图像中合成高保真新视角
- **方法**：使用粗糙点云渲染图作为控制，通过迭代式相机轨迹规划扩展三维场景的生成范围

**FlexWorld**
- **目标**：从单图出发，生成灵活观察的大范围 3D 场景（基于 3DGS）
- **流程**：Progressive 3D expansion → Update → Integration → Optimization

**其他重要工作**：
- **Marble**：持久化世界模型
- **FlashWorld**：秒级 3DGS 生成
- **CAT4D**：多视角动态视频 4D 生成
- **ReCamMaster**：相机轨迹条件的生成式动态重渲染
- **InSpatio-World**：低延迟时空自回归 4D 视频生成

## 五、总结、展望与前沿工作

### 5.1 空间生成的关键问题

- **几何信号控制的视频生成**：长程几何一致性如何保证？
- **显式三维物体/场景生成**：模型可扩展性如何突破？
- **时空间融合**：时间动态从小时级（电影）、天级（游戏）到终身（元宇宙）
- **新范式探索**：扩散自回归？Transformer？数据表示？

### 5.2 空间智能与具身交互前沿

| 工作 | 年份 | 核心贡献 |
|------|------|----------|
| **Cambrian-S** | 2025 | 将空间能力延伸至时空维度。不仅看当前，还要记住过去并预测未来空间状态 |
| **RoboTracer** | 2025 | 解决 VLM/VLA 只能理解简单空间指令，但缺乏多步尺度推理和 reasoning trace 的问题 |

## 六、核心趋势提炼

1. **从专用到统一**：无论是目标检测还是跨模态推理，趋势都是从 agentic 编排走向 unified 基础模型，通过共享表示空间实现内在化推理。
2. **从优化到学习**：三维重建领域（Modern3D）正从传统的多阶段优化流程（SfM+MVS+Fusion）走向端到端的前馈网络（Feedforward 3DGS、PointMap）。
3. **从静态到动态**：空间智能从单帧/静态场景重建向 4D 时空建模、世界模型、持久化环境演进。
4. **从感知到交互**：开放世界目标检测与 Think3D 等工作显示，视觉系统正从被动感知走向主动推理与交互式 3D Chain-of-Thought。
5. **表示学习的关键性**：语义对齐的离散视觉表示（MBAQ）与稀疏体素（O-Voxel）等新型数据表示，成为跨模态推理与生成质量的决定性因素。

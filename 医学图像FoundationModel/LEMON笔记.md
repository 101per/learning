## 一、为什么做（Motivation / Problem）

### 1.1 核心问题
现有**开放式手术数据集**规模极小：
- 通常 **< 100 个视频**，**< 30 小时** footage
- 导致模型**泛化能力差**（poor generalization）

### 1.2 数据稀缺的根本原因
| 障碍           | 说明                                    |
| -------------- | --------------------------------------- |
| 医学数据复杂性 | 手术场景高度专业、视觉差异大            |
| 隐私法规严格   | 患者隐私保护限制数据收集                |
| 标注成本高     | 需要专业医学知识，标注昂贵              |
| 现有数据集局限 | 覆盖术式单一，含非手术内容（如图3对比） |

### 1.3 现有数据集的规模对比

### 2.3 LemonFM 基础模型

#### 2.3.1 核心思想
手术基础模型需要学习两种不变性：
1. **时序不变性**：相邻帧间器械和组织的微小运动
2. **跨患者不变性**：同种术式下不同患者的细微外观差异（如器官颜色变化）

#### 2.3.2 增强知识蒸馏（Augmented Distillation）

基于 **DINO** 框架改进，核心损失函数：

$$\mathcal{L} = -\sum_{i=1}^{I}\sum_{\mathbf{u}\in U_i}\sum_{\substack{\mathbf{v}\in V_i\cup W_i\\\mathbf{u}\neq\mathbf{v}}}\sum_{z=1}^{C} P_t(z|\mathbf{u}) \log P_s(z|\mathbf{v})$$

**符号说明：**
| 符号         | 含义                                     |
| ------------ | ---------------------------------------- |
| $I$          | 图像总数                                 |
| $U_i$        | 输入图像 $x_i$ 的 **2 个全局增强**       |
| $V_i$        | $x_i$ 的 **2 个全局增强 + 4 个局部裁剪** |
| $W_i$        | **增强池**中的图像（核心创新）           |
| $P_t, P_s$   | Teacher / Student 网络的 softmax 分布    |
| $C = 2^{16}$ | 输出维度                                 |

**$W_i$ 增强池的构建策略（图4）：**

```
输入帧
   ├──→ 最近邻检索（同术式其他视频）
   │      └── 余弦距离 < 3×(与前一帧距离) → 加入池
   │
   └──→ 若池未满，补充相邻帧 (t-2, t-1, t+1, t+2)
   
池容量：4 张图像
每张生成 4 个增强裁剪 → 共 16 个增强视图
```

**超参数选择依据：**
- 距离度量：**余弦相似度** > L2 距离（AutoLaparo +4pp, Cholec80 +3.5pp）
- 阈值因子：**3×** 为近最优（1.5× 多样性不足，6× 引入噪声）

#### 2.3.3 网络架构

| 组件       | 配置                                   |
| ---------- | -------------------------------------- |
| Backbone   | ConvNeXt-L（Teacher & Student 同架构） |
| 优化器     | AdamW                                  |
| 学习率     | 5e-4（初始）→ 1e-6（最小）             |
| Batch size | 24/GPU × 8 GPUs = 192                  |
| 训练轮数   | 60 epochs（10 warm-up）                |
| 精度       | FP16                                   |
| 硬件       | 8× NVIDIA V100 (32GB)                  |

**设计选择验证（消融实验）：**
- **ConvNeXt > ViT**：分割任务 +10.7pp mDice（ConvNeXt 保留局部细节如器械尖端）
- **判别式 > 生成式**：MAE/VideoMAEv2 在冻结 backbone 时表现差
- **图像编码器 > 视频编码器**：VideoMAEv2 分割仅 65.7% vs LemonFM 81.3%；推理速度 10ms vs 65ms/帧

### 2.4 LemonFM-Vid（视频分类头）

用于 LEMON 提出的两个新任务：
1. **35类多标签术式分类**
2. **二分类手术类型**（机器人/非机器人）

**帧聚合公式：**

$$\mathbf{v}_e = \sum_{j=0}^{J-1} \omega_j \boldsymbol{\phi}_j$$

其中典型性权重：
$$\omega_j = \frac{t(\boldsymbol{\phi}_j)}{\epsilon + \sum_{m=0}^{J-1}t(\boldsymbol{\phi}_m)}, \quad t(\boldsymbol{\phi}) = \left(\frac{1}{K}\sum_{\boldsymbol{\eta}\in K\text{-NN}(\boldsymbol{\phi})} d(\boldsymbol{\phi}, \boldsymbol{\eta})\right)^{-1}$$

- $K=20$：最近邻数
- $d$：余弦距离
- $\epsilon=10^{-8}$：数值稳定性

## 四、形式化总结

### 4.1 问题定义
设手术视觉任务为 $\mathcal{T}$，现有数据集为 $\mathcal{D}_{\text{existing}}$，满足 $|\mathcal{D}_{\text{existing}}| \ll \mathcal{D}_{\text{surgery}}$（真实手术数据分布）。由于数据稀缺，模型 $f_\theta$ 的泛化误差 $\mathbb{E}_{(x,y)\sim\mathcal{D}_{\text{surgery}}}[\mathcal{L}(f_\theta(x), y)]$ 居高不下。

### 4.2 方法论
**LEMON 数据集**：
$$\mathcal{D}_{\text{LEMON}} = \{(x_i, y_i^{\text{proc}}, y_i^{\text{type}})\}_{i=1}^{N}, \quad N=4,194, \quad |Y^{\text{proc}}|=35$$

**LemonFM 预训练目标**：
$$\min_\theta \mathcal{L}_{\text{distill}}(\theta; \mathcal{D}_{\text{LEMON}}) + \lambda \mathcal{L}_{\text{aug}}(\theta; \mathcal{N}_k(x), \mathcal{T}(x))$$

其中 $\mathcal{N}_k(x)$ 为同术式跨患者最近邻，$\mathcal{T}(x)$ 为时序邻域帧。

### 4.3 核心定理（实验验证）
$$\forall \mathcal{T} \in \{\text{phase}, \text{tool}, \text{action}, \text{segmentation}\}, \quad \text{Perf}(\text{LemonFM}, \mathcal{T}) > \text{Perf}(\text{baseline}, \mathcal{T})$$

且满足数据效率：
$$\text{Perf}(\text{LemonFM}, 50\%\text{ data}) > \text{Perf}(\text{baseline}, 100\%\text{ data})$$
